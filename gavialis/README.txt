GAVIALIS — NATURAL GHARIAL PHOTO + ORIGIN STORY FIX

This patch keeps the current GAVIALIS charcoal / acid-green streetwear design, product grid, bag and 3D Fit Lab. It fixes the hero/story/closing image URLs to point directly at verified natural gharial photographs hosted by Wikimedia Commons, removing the incorrect image that showed a model in clothing.

It also rewrites the Origin section to focus on Gavialis gangeticus, its Indian river habitat and conservation threats, without claiming that customer purchases automatically fund donations.

INSTALL:
1. Unzip this archive into the inner project folder: ~/Desktop/gavialis/gavialis
2. Choose Replace/overwrite when prompted.
3. Restart the dev server (Ctrl+C, then npm run dev) and hard-refresh the browser (Cmd+Shift+R).
