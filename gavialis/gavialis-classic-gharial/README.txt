GAVIALIS — CLASSIC STOREFRONT / GHARIAL THEME

This keeps the earlier premium editorial storefront layout and changes the imagery/copy/accent details to the GAVIALIS gharial / Chambal identity.

Files to replace in your existing Vite project:
- src/App.jsx
- src/App.css

Your existing src/assets/hero.png is used for the hero/story/closing campaign art.

Put the three product image files in the project's public folder and name them exactly:
- public/hoodie.png
- public/shorts.png
- public/ghost.png

These are the three product cards. If your current files have names like "zipper hoodie gavialis.png" and "shorts gavialis.png", copy them into public and rename the copies to the names above. Keep the originals if you want.

Then run from the inner project folder:
  npm run dev

This is the storefront UI and session-only bag. Checkout is still a placeholder; no real payment is connected.
